# Flappy Bird (KAN-17)

A simple Flappy Bird-style browser game built with **vanilla HTML, CSS, and JavaScript**.

## How to Run

1. Clone this repository.
2. Open the `flappy-bird/index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
   - No build step or server is required.

## Controls

- **Space** or **Arrow Up** – Flap / jump
- **Mouse click** on the game area – Flap
- **Touch** on the game area (mobile) – Flap

## Gameplay

- Press any flap control to start the game.
- Guide the bird through the gaps between the pipes.
- Each pipe you successfully pass increases your score by 1.
- Colliding with a pipe, the ground, or the top of the screen ends the game.
- Your **best score** is saved in `localStorage` and shown on the UI.
